# XingyuBot 伺服器管理後台：投票

## 背景與動機

伺服器管理後台已有通知、動態語音、反應身分組、私人頻道、警告、抽獎與基本設定（見 [server-dashboard-spec.md](server-dashboard-spec.md)、[server-dashboard-dynamic-voice-spec.md](server-dashboard-dynamic-voice-spec.md)、[server-dashboard-roles-tickets-moderation-spec.md](server-dashboard-roles-tickets-moderation-spec.md)）。投票還只能在 Discord 上操作：

- 任何人都能用 `/poll create` 發起投票，但管理員看不到伺服器裡有哪些投票。
- 指令的選項全塞在一行，選項用英文逗號隔開、身分組權重寫成「身分組,權重,身分組,權重」，不好填也容易填錯。
- 投票沒有截止時間，只能由發起人按「結算投票」結束。發起人忘了或離開伺服器時，投票會一直停在進行中，直到 bot 重啟時被「建立超過 28 天」的規則默默結束，Discord 上的訊息也不會更新。
- 投票的資料只記了訊息，沒記頻道，事後找不回投票在哪裡。
- 結果只能在 Discord 上看，無法匯出。

現行投票的規則（後台沿用，不改變）：
- 投票可以設定實名或匿名、結算前能不能看結果、只限發起人看結果、每人最多可投幾個選項、限定哪些身分組能投票、身分組權重（擁有身分組的人票數乘上倍數，取最高），以及小帳不算有效票。
- 訊息上的按鈕有：結算投票（只有發起人與 bot owner 能按）、查看結果、取消投票（投票的人收回自己的票）、目前選擇，以及每個選項一顆按鈕。
- 投票只有「進行中」與「已結算」兩種狀態。

## 目標與非目標

**目標**
- 有 Manage Messages 的管理員能在後台看到伺服器的所有投票、各選項票數，以及實名投票的投票明細。
- 能從後台用表單發起投票，設定項目與指令相同，另外可以設截止時間。
- 投票可以設截止時間，到時自動結算並更新 Discord 上的訊息；指令也能設。
- 發起人能在後台結算、刪除自己的投票；發起人離開伺服器後，管理員能代為處理。
- 能把結果匯出成 CSV。
- 進行中的投票，詳細頁會自動更新票數。
- 寬度 360px 以上的手機可以完整操作。

**非目標**
- 建立後修改投票內容或截止時間。
- 可以改投的投票（`can_change_vote`），維持未實作。
- Discord 上按鈕與指令的權限變更：「結算投票」仍只有發起人與 bot owner 能按。
- 異動歷史、英文介面。

## 已定案的前提

- 沿用前幾案的地基：登入與 session、伺服器清單、區塊權限與導覽、bot 不在伺服器或使用者沒有權限時的處理、伺服器端重新檢查所有限制、360px 可操作。本文只寫不同或新增的部分。
- 後台 API 放在 XingyuBot 的 web 服務，前端放在 domalyze_frontend，與前幾案相同。
- 後台與指令操作的是同一份投票資料：用指令建立的投票在後台看得到，後台建立的在 Discord 上也是一般的投票。

## 範圍

- 伺服器頁側欄新增「投票」區塊。
- 投票清單、單一投票詳細頁（含定時自動更新）、從後台發起、結算、刪除、匯出 CSV。
- 截止時間與自動結算，後台與 `/poll create` 都能設。
- 投票開始記錄所在頻道與正確的投票訊息；既有投票顯示「頻道未知」。
- bot 啟動時「建立超過 28 天就結束」的規則改成 30 天，並和正常結算一樣更新訊息。
- `/poll create` 套用與後台相同的欄位限制。

## 詳細規格

### 頁面與導覽

- 側欄順序：通知、動態語音、反應身分組、私人頻道、警告、抽獎、投票、基本設定。
- 投票區塊有自己的網址，進入條件與其他區塊相同。

### 權限

| 動作 | 需要的權限 | 額外條件 |
|---|---|---|
| 看清單與詳細頁、匯出 | Manage Messages | 看得到的內容依〈結果的可見範圍〉 |
| 發起投票 | Manage Messages | 操作者本人也要能在選定的頻道發言 |
| 結算、刪除 | Manage Messages | 操作者是發起人或 bot owner；或發起人在按下的當下已不在伺服器 |

- bot owner 指 Discord 上這個 bot 應用程式的擁有者，與 Discord 內「結算投票」按鈕認定的 owner 相同。
- 發起人是否還在伺服器，以按下結算或刪除的那一刻為準。
- 沒有資格結算或刪除的人，畫面上看不到按鈕；直接呼叫 API 也會被擋下。

### 結果的可見範圍

後台照投票自己的設定決定給誰看什麼。發起人與 bot owner 視同「發起人」；發起人已不在伺服器時，有 Manage Messages 的管理員也視同發起人；其他管理員視同一般成員：

| 投票設定 | 進行中 | 已結算 |
|---|---|---|
| 所有人都能預先查看結果 | 所有人看得到票數 | 所有人看得到票數 |
| 僅限發起人能預先查看結果 | 只有發起人看得到票數 | 所有人看得到票數 |
| 結果將在結束時公佈 | 沒有人看得到票數 | 所有人看得到票數 |

- 「預先查看結果」關閉時，不論「僅限發起人能查看結果」怎麼設，都歸為「結果將在結束時公佈」，與 Discord 訊息上的說明一致。
- 匿名投票不論誰看、什麼時候看，都只有各選項的票數，看不到誰投了什麼；實名投票在看得到票數時，另外列出每一票的成員、選項、權重與投票時間。
- 票數一律是加權後的數字。
- 設了「小帳不算有效票」的投票（只能由指令建立），票數、投票人數、實名明細與匯出都排除小帳的票，與 Discord 上的結果一致。
- 看不到票數時，詳細頁只顯示投票設定，並說明什麼時候會公佈。
- 詳細頁、匯出檔與 API 回應都遵守同一套規則，直接呼叫 API 也拿不到不該看到的內容。

### 清單

- 進行中的投票全部列在第 1 頁最上面，不算在分頁筆數內；已結算的依結算時間由新到舊，每頁 20 筆。
- 預設只列最近 90 天內建立的投票，可以切換成顯示全部；進行中的不受 90 天限制。
- 每筆顯示標題、發起人、所在頻道、狀態（進行中或已結算）與投票人數（投過票的不重複成員數，一人投多個選項算一人；看不到票數的投票也顯示）。已結算的顯示結算時間；進行中的顯示截止時間，沒設就顯示「沒有截止時間」。
- 所在頻道未知的投票顯示「頻道未知」。
- 星羽在投票頻道缺少權限時，照抽獎的做法，在清單與詳細頁顯示缺少的權限與後果，見〈bot 權限警告〉。
- 沒有任何投票時，顯示簡短說明：可以在這裡發起，或用 `/poll create` 發起。

### 單一投票

- 顯示標題、發起人、所在頻道與跳到投票訊息的連結、建立時間、截止時間或結算時間、投票設定（實名或匿名、結果可見範圍、每人可投幾個選項、限定身分組、身分組權重）。
- 被刪除的身分組顯示「已刪除的身分組」；已離開伺服器的成員顯示「已離開的成員」。
- 各選項的票數與實名投票的明細依〈結果的可見範圍〉顯示。
- 進行中的投票每 30 秒自動更新一次；已結算的不再更新。另有手動重新整理。
- 頻道未知的投票沒有訊息連結。
- 結算時訊息沒能更新的投票，標示「訊息未更新」與原因。

### bot 權限警告

- 檢查星羽在投票所在頻道的「檢視頻道」「讀取訊息歷史」「發送訊息」；缺少任一項時，清單顯示簡短警告，詳細頁顯示完整說明：缺哪些權限，以及結算、自動結算與刪除時會無法更新或刪除投票訊息，請到頻道設定補上。
- 只警告，不擋操作：缺權限時仍可結算與刪除，結果照〈結算〉〈刪除〉的失敗處理。
- 頻道已不存在或頻道未知時不顯示權限警告，改顯示頻道狀態。
- 發起表單的頻道選單中，星羽或操作者不能發言的頻道不能選，並標示原因。

### 時間

- 所有畫面與匯出檔的時間一律以台灣時間（UTC+8）顯示。

### 發起投票

**欄位**（預設值與 `/poll create` 相同）

| 欄位 | 預設 | 限制 |
|---|---|---|
| 頻道 | — | 必填，只能選文字頻道或公告頻道，且 bot 與操作者都能在該頻道發言；不含討論串、論壇與語音頻道內的文字聊天 |
| 標題 | — | 必填，45 字以內 |
| 選項 | — | 1 到 20 項，每項 80 字以內，不能重複 |
| 顯示投票人（實名） | 否 | — |
| 預先查看結果 | 是 | — |
| 僅限發起人能查看結果 | 否 | — |
| 一人最多可投票數 | 1 | 1 到 20，且不超過選項數 |
| 限定身分組 | 不限 | 可多選 |
| 身分組權重 | 無 | 每個身分組 1 到 10 |
| 截止時間 | 無 | 選填，用日期時間選擇器，須在未來，最長為建立後 30 天，精確到分鐘 |

- 不提供「小帳不算有效票」。
- 發起人是操作的管理員：訊息上顯示他的名字與頭像，他在 Discord 上也能按「結算投票」，看「僅限發起人」的結果。
- 送出後由 bot 在指定頻道發出投票訊息，與指令建立的投票相同。發送失敗時不建立投票，並顯示原因，例如 bot 沒有發言權限或頻道已不存在。
- 建立後不能修改任何內容，包括截止時間。

### 截止時間與自動結算

- 有截止時間的投票，投票訊息的說明裡顯示截止時間。
- 有截止時間的投票，到時自動結算，效果與發起人按下「結算投票」相同：訊息上的按鈕移除，改成結果與圓餅圖。
- bot 在截止時間沒有運作時，上線後立刻補結算。啟動時先處理已到期的補結算，再套用下面的 30 天規則。
- 自動結算或補結算時訊息沒能更新（訊息已刪、頻道不在或頻道未知、bot 無法編輯），照樣結算，詳細頁標示「訊息未更新」與原因，不另外通知。
- 截止前仍可以手動結算。
- `/poll create` 新增選填的截止時間選項，寫法與 `/giveaway create` 的結束時間相同：時長（如 `30m`、`2h`、`7d`）或日期時間（如「明天 20:00」）都能輸入，最小單位 1 分鐘，最長 30 天。
- bot 啟動時，建立超過 30 天、仍在進行中的投票會被結束（原本是 28 天），訊息更新方式與正常結算相同。截止時間最長 30 天，所以有設截止時間的投票都會在這之前照截止時間結算。

### 指令的修改

- `/poll create` 套用與後台相同的限制：標題 45 字以內、選項不能重複且每項 80 字以內、身分組權重 1 到 10，另外加上截止時間選項（見上）。
- 其他指令與按鈕的行為維持現況。

### 結算

- 只有進行中的投票可以結算，要二次確認。
- 效果與發起人按下「結算投票」相同。
- 投票訊息已被刪除、頻道已不存在、頻道未知或 bot 無法編輯訊息時，照樣結算，並告知管理員訊息沒有更新的原因。
- 執行當下投票已經結算，例如剛好到期或發起人剛在 Discord 上按了結算，視為成功，並顯示最新結果。

### 刪除

- 進行中與已結算的投票都可以刪除，要二次確認，並說明無法復原。
- 刪除會一併刪掉 Discord 上的投票訊息，以及投票的所有選項、身分組設定與成員投的票。投票就此不存在：個人區不再顯示這筆投票，公開頁的投票參與次數跟著減少。
- 訊息已不在、頻道已不存在或頻道未知時，照樣刪除資料；bot 無法刪除訊息時，照樣刪除資料，並告知管理員訊息沒有刪掉的原因。
- 留在 Discord 上的訊息，有人按它的按鈕時，回覆「此投票已不存在」，並嘗試移除按鈕。
- 執行當下投票已經被刪除，視為成功，並回到清單。

### 匯出

- 匯出 CSV，內容與詳細頁當下看得到的相同。
- 檔案開頭一段各選項票數，欄位是選項、票數。實名投票接著空一列，再一列一票，欄位是成員名稱、成員 ID、選項、權重、投票時間；已離開的成員，名稱欄寫「已離開的成員」。
- 編碼為 UTF-8 含 BOM，讓 Excel 正確顯示中文。檔名含投票 ID 與標題。
- 看不到票數的投票不能匯出。

### 頻道與訊息的記錄

- 之後建立的投票，不論來自指令還是後台，都記下所在頻道與正確的投票訊息。
- 既有投票記下的訊息編號其實不是投票訊息，找不回訊息與頻道，一律顯示「頻道未知」，不補查。

## 驗收條件

1. 用指令與後台各建立一個「所有人都能預先查看結果」的投票，兩者都出現在清單上，票數與 Discord 上「查看結果」看到的一致。
2. 匿名投票的詳細頁、匯出檔與 API 回應都看不到投票人。
3. 「結果將在結束時公佈」的投票，進行中時詳細頁、匯出與 API 都看不到票數，結算後看得到。
4. 「僅限發起人能預先查看結果」的投票進行中時，發起人在詳細頁看得到票數，其他管理員看不到。
5. 設 2 分鐘截止的投票，到時自動結算，訊息改成結果；截止前停掉 bot、過了截止時間再啟動，上線後補結算。
6. 非發起人的管理員在詳細頁看不到結算、刪除按鈕，直接呼叫 API 回權限錯誤；發起人離開伺服器後重新整理，按鈕出現且操作成功。
7. 從後台刪除投票後，Discord 上的訊息消失，個人區不再顯示這筆投票。
8. 先在 Discord 刪掉投票訊息，再從後台結算，投票照樣結算，並顯示訊息沒有更新的原因。
9. 選一個 bot 沒有發言權限的頻道發起投票，投票沒有建立，畫面顯示原因。
10. 「所有人都能預先查看結果」的實名投票詳細頁開著，另一人在 Discord 投票後 30 秒內，票數與明細都更新。
11. 有超過 20 筆已結算投票時分頁正確，進行中的列在第 1 頁最上面；建立超過 90 天的已結算投票預設不列出，切換成全部後出現。
12. 本功能上線前建立的投票顯示「頻道未知」、沒有訊息連結；從後台結算時照樣結算，並說明訊息沒有更新。
13. 寬度 360px 的畫面能完成發起、檢視、結算、刪除與匯出。
14. 實名投票的匯出檔用 Excel 開啟中文正常，開頭是各選項票數、接著是逐票明細，內容與當下詳細頁一致；匿名投票的匯出檔只有各選項票數。
15. `/poll create` 輸入 `2m` 的截止時間，訊息上顯示截止時間，到時自動結算；輸入超過 30 天、重複選項或超過 45 字的標題會被擋下。
16. 從後台刪除投票時 bot 刪不掉訊息，之後有人按留下的按鈕，收到「此投票已不存在」。
17. 拿掉星羽在投票頻道的「讀取訊息歷史」後，清單與詳細頁顯示缺少的權限與後果，仍可結算。

## 上線順序

bot 與 API 先上線，前端後上線。

## 考慮過但捨棄的方向

- **只做檢視與提前結算**（比照抽獎的範圍）：使用者選擇完整接入，包括發起、刪除、匯出與自動更新。
- **管理員一律看得到匿名投票的投票人**：與 Discord 訊息上寫的「匿名投票」不一致。
- **管理員不必是發起人就能結算、刪除**（抽獎的做法）：投票維持發起人主導，只在發起人離開後才開放。
- **刪除時保留成員的票**：刪除就是投票不存在，不留殘餘紀錄。
- **真即時推播票數**：工程量明顯較大，30 秒定時更新已足夠。
- **建立後可修改內容或截止時間**：會影響已經投下的票。
- **掃描頻道歷史找回舊投票的訊息**：掃描受 rate limit、耗時長，收益只有舊投票的連結與訊息更新。

## 已知限制與風險

- 沒設截止時間、發起人仍在伺服器但不處理的投票，只能等 bot 重啟時的 30 天規則結束。
- 本功能上線前建立的投票找不回訊息，從後台結算或刪除時無法更新或刪除它的 Discord 訊息；bot 重啟後這些投票的按鈕也可能已經失效，這是既有問題，不在這次修復範圍。
